# AAA Narrative 2D Environment Wallpaper

**Edition:** Arkane Narrative Environment Edition V1
**Version:** 1.0
**Intent:** Narrative RPG desktop wallpaper with Arkane Studios visual DNA

## Master Prompt

A cinematic, ultra high-detail 2D narrative environment wallpaper of `{subject}`, executed primarily in the visual language of Arkane Studios environmental concept art, Dishonored urban vistas, and painterly narrative worldbuilding art.

Adhere strictly to a 60/30/10 color palette:

* **Primary color:** `{primary_color}` - 60%
* **Secondary color:** `{secondary_color}` - 30%
* **Accent color:** `{accent_color}` - 10%

The image must prioritize atmosphere, readable silhouettes, architectural identity, environmental storytelling, and painterly composition over character presence.

No central character is required. If people appear, they must remain small, secondary, and part of the environment.

## Focal Hierarchy System

**Priority:** ABSOLUTE

| Element                           | Detail allocation |
| --------------------------------- | ----------------: |
| Main landmark or focal structure  |              100% |
| Immediate foreground storytelling |               80% |
| Important environmental props     |               65% |
| Midground architecture            |               50% |
| Secondary silhouettes             |               35% |
| Distant skyline                   |               25% |
| Background atmosphere             |               15% |
| Peripheral space                  |               10% |

Rules:

* The viewer’s eye must immediately understand the location.
* The main focal structure receives the highest detail.
* No secondary detail may compete with the main environmental subject.
* Detail density must progressively dissolve toward the edges and distance.
* The wallpaper must remain readable even at desktop scale.
* Avoid visual clutter that makes the image tiring as a background.

## Peripheral Abstraction System

**Priority:** ABSOLUTE

* Detail density progressively dissolves away from the main focal structure.
* Distant buildings may simplify into silhouettes and value masses.
* Visual suggestion is preferred over exhaustive rendering.
* Use larger brushstrokes in peripheral areas.
* Lost-and-found edges increase toward the borders.
* Peripheral forms should merge into larger atmospheric shapes.
* Painterly abstraction is preferred over hyper-rendering.
* Abstraction should appear intentional and artistic rather than blurry.

## Detail Sacrifice Hierarchy

**Priority:** ABSOLUTE**

When image complexity increases, detail must be removed from lower-priority elements before reducing quality in higher-priority elements.

Sacrifice detail in this order:

1. Peripheral space
2. Distant skyline
3. Background atmosphere
4. Secondary silhouettes
5. Minor props
6. Repeated windows
7. Repeated pipes and machinery
8. Midground architecture
9. Foreground storytelling props
10. Main landmark or focal structure

## Environmental Storytelling

**Type:** Narrative Symbolism

* Suggest rather than explain.
* Imply history through architecture, wear, signage, smoke, stains, repairs, barricades, vehicles, tools, ruins, or civic symbols.
* Use silhouettes and value masses.
* Avoid over-rendered crowds.
* Avoid unnecessary decorative detail.
* Every visible element should reinforce the identity of the place.
* The environment should feel inhabited, political, industrial, decaying, sacred, wealthy, poor, dangerous, or ceremonial according to the subject.
* The image should tell a story before any text is read.

### Edge Control

| Region                        | Edge treatment     |
| ----------------------------- | ------------------ |
| Main focal structure          | Sharpest           |
| Foreground narrative elements | Controlled         |
| Midground architecture        | Moderately defined |
| Distant skyline               | Softened           |
| Atmospheric background        | Lost-and-found     |
| Peripheral space              | Simplified         |

### Architecture Rendering

* Use large architectural masses first.
* Prioritize silhouette over ornament.
* Windows, pipes, signs, bridges, towers, rails, cranes, and rooftops should be readable but not over-rendered.
* Repeated architectural details may be suggested through pattern and brushwork.
* Avoid technical blueprint precision unless requested by the user.

### Crowd and Figure Treatment

**Priority:** LOW

* Human figures are optional.
* If present, they must remain secondary.
* Use silhouettes, gestures, and group shapes rather than detailed faces.
* No individual person should become the main subject unless explicitly requested.
* Crowds should support the mood of the location.

### Peripheral Treatment

* Larger brushstrokes
* Reduced detail density
* Merged value shapes
* Lost edges
* Painterly simplification
* Controlled abstraction
* Usable negative space for desktop readability

## Environmental Identity Enforcement

**Priority:** ABSOLUTE

* Place identity over spectacle.
* Architecture over decoration.
* Silhouette over texture.
* Narrative atmosphere over visual excess.
* Avoid generic fantasy cityscapes.
* Avoid same-city syndrome.
* The location must feel specific to Astrael.
* The image must communicate social class, politics, industry, decay, faith, crime, wealth, or civic power through visible environmental details.

## Wallpaper Usability System

**Priority:** HIGH

* The image must work as a PC desktop wallpaper.
* Avoid placing excessive high-contrast detail across the entire frame.
* Preserve at least one calmer visual area suitable for desktop icons.
* Maintain strong readability at 16:9.
* Avoid central clutter.
* Avoid tiny important details that only work when zoomed in.
* The composition should feel immersive but not visually exhausting.

## Arkane DNA Enforcement

**Priority:** ABSOLUTE

* World design takes priority over rendering polish.
* Planes before gradients.
* Value masses before texture.
* Identity before spectacle.
* Narrative before decoration.
* Painterly readability before visual complexity.
* Concept art first, wallpaper second.
* The environment should feel observed rather than staged.
* Architecture, props, wear, smoke, machinery, signage, and silhouettes must communicate the story of the place.

## Fail Safe

Protect the main environmental identity first. Protect the focal structure second. Protect atmosphere third. Progressively simplify crowds, distant buildings, repeated machinery, peripheral architecture, and background details before sacrificing readability.
