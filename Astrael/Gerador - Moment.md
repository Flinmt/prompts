# Master Prompt

A cinematic, painterly 2D narrative illustration of `{subject}`, executed primarily in the visual language of Arkane Studios character promotional art, Dishonored character portraits, and painterly narrative concept art.

Every illustration should represent a **single witnessed moment** in the character's life.

It should never resemble a posed portrait, an action spectacle, an environment showcase or a promotional illustration.

Instead, it should feel as though the viewer arrived at a real place and witnessed a meaningful instant that was already unfolding.

The character is always the emotional and visual center of the image.

Everything else—including the environment, secondary figures and surrounding activity—exists only to reveal who that character is through the moment being witnessed.

The illustration should naturally suggest that something happened moments before the image and that something will happen moments after it.

Adhere strictly to a 60/30/10 color palette.

- **Primary Color:** `{primary_color}` — 60%
- **Secondary Color:** `{secondary_color}` — 30%
- **Accent Color:** `{accent_color}` — 10%

Construct every element through:

- sculptural planes
- large value masses
- strong shape language
- visible painterly brushwork

before considering surface detail.

Character identity, facial construction and narrative clarity always take priority over rendering polish.

The face should attract the viewer through expression, structure and readability rather than photographic realism.

Visual complexity, edge sharpness and detail density progressively dissolve as distance from the face increases.

# Composition System

| Property | Direction |
|----------|-----------|
| Aspect Ratio | 9:16 |
| Composition | Dynamic asymmetry |
| Layout | Full body |
| Character Scale | Character occupies approximately 70–80% of the image height |
| Camera | Eye level or slight low angle |
| Environment | Compact, lived-in and subordinate |
| Balance | Character remains the unquestionable focal point |

The image should feel like a witnessed narrative moment.

The viewer should feel present rather than positioned.

The camera behaves like an observer who happened to arrive at exactly the right moment.

The environment naturally frames the character without becoming a competing subject.

---

# Captured Moment System

**Priority:** ABSOLUTE

Every illustration should answer, visually:

- What happened five seconds before this image?
- What is happening right now?
- What will probably happen next?

The answers should never be explained through text.

They should emerge naturally through:

- posture
- expression
- gesture
- objects
- surroundings
- interactions
- visible consequences

The image should feel like one frozen instant from a much larger story.

| Element | Priority |
|---------|---------:|
| Face | 100% |

| Neck & Upper Torso | 90% |

| Storytelling Props | 60% |
| Costume | 45% |
| Lower Clothing | 30% |
| Narrative Background | 20% |

Rules

- The face receives the greatest visual clarity.
- The viewer immediately notices the face.
- Nothing competes with the character.
- Detail progressively dissolves away from the face.
- Clarity comes from structure, not microscopic rendering.

---

# Peripheral Abstraction

- Suggest rather than describe.
- Merge distant forms into large value masses.
- Simplify peripheral anatomy.
- Broaden brushwork toward the edges.
- Increase lost-and-found edges.
- Favor painterly interpretation over exhaustive rendering.

Peripheral abstraction should always feel intentional.

---

# Narrative Environment

The environment is an extension of the character.

It exists because this moment happens here.

It should naturally answer questions such as:

- Where does this person work?
- Why is this place important?
- Why is this moment happening here?

Choose one dominant environmental element that naturally organizes the scene.

Examples:

- desk
- workbench
- counter
- window
- chair
- machine
- stage
- podium
- vehicle
- archive
- laboratory

Describe how the character interacts with that element.

The environment should feel occupied, functional and lived-in.

Avoid environments that exist only as decoration.

---

# Narrative Background

Background activity should quietly reinforce the moment without competing with the protagonist.

Secondary figures should exist only to contextualize the scene.

Prefer:

- workers
- clerks
- assistants
- guards
- journalists
- technicians
- pedestrians

They should never become secondary protagonists.

# Rendering Standard

Style:

Arkane Studios Narrative Character Concept Art

Characteristics:

- painterly finish
- visible brushwork
- sculptural construction
- large value masses
- simplified materials
- minimal lineart
- structural readability

Celebrate painting.

Never imitate photography.

---

# Edge Hierarchy

Face → Sharpest

Eyes → Sharpest

Upper torso → Controlled

Hands → Moderately defined

Costume → Soft

Background → Mostly lost-and-found

---

# Material Rendering

Represent materials primarily through:

- silhouette
- value
- shape
- edge variation

Texture is always secondary.

---

# Hair Rendering

Construct hair as large sculptural masses.

Avoid excessive individual strands.

Hair remains subordinate to facial identity.

---

# Hand Rendering

Hands should support storytelling.

Readable.

Believable.

Painterly.

Never compete with the face.

---

# Character Performance

Every character should appear genuinely occupied with the moment.

Avoid poses that appear arranged for the viewer.

Avoid:

- heroic poses
- fashion poses
- promotional poses
- static standing
- looking directly at the viewer without narrative reason

The viewer should feel like an unnoticed observer.

---

# Facial Identity

Identity before beauty.

Structure before smoothness.

Expression before attractiveness.

Architecture before texture.

Preserve individuality.

Avoid same-face syndrome.

---

Character over rendering.
