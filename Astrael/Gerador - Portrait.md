---

# Master Prompt

A cinematic, painterly 2D narrative character portrait of `{subject}`, executed primarily in the visual language of Arkane Studios character promotional art, Dishonored character portraits, and painterly narrative concept art.

Every illustration should resemble an official RPG character portrait rather than an action scene, cinematic frame, or environment illustration.

The character is always the primary subject of the composition. The surrounding environment exists only to reinforce the character's identity, profession, social status and narrative context.

Adhere strictly to a 60/30/10 color palette:

- **Primary color:** `{primary_color}` — 60%
- **Secondary color:** `{secondary_color}` — 30%
- **Accent color:** `{accent_color}` — 10%

Construct every element through sculptural planes, large value masses, strong shape language and visible painterly brushwork before considering fine surface detail.

Character identity, facial structure and narrative presence must always take priority over glamour, beauty standards, decorative rendering and visual excess.

The face must immediately attract the viewer through clarity, expression and structure rather than photographic realism.

Detail density, edge sharpness and visual complexity must progressively dissolve as distance from the face increases.

# Composition System

| Property | Direction |
|----------|-----------|
| Rule | Dynamic asymmetry using the Rule of Thirds |
| Aspect Ratio | 9:16 |
| Layout | Full-body portrait with the entire figure clearly visible |
| Character Scale | Character occupies approximately 70–80% of the image height |
| Camera | Eye level or slight low angle |
| Environment Role | Compact narrative environment supporting the character |
| Balance | Character remains visually dominant at all times |

The image should feel like a carefully composed narrative portrait rather than an action sequence.

The environment should naturally frame the character without competing for attention.

---

# Focal Hierarchy System

**Priority:** ABSOLUTE

| Element | Detail Allocation |
|---------|------------------:|
| Face | 100% |
| Eyes | 100% |
| Neck and Upper Torso | 90% |
| Hands | 65% |
| Storytelling Props | 60% |
| Costume | 45% |
| Lower Clothing | 30% |
| Background Storytelling | 20% |
| Environment | 10% |

Rules:

- The face receives the greatest visual clarity.
- The viewer's eye should immediately lock onto the face.
- No secondary element may compete with the face.
- Visual complexity should progressively decay away from the face.
- The image should feel painted outward from the character.
- Clarity should come from structure rather than excessive rendering.

---

# Peripheral Abstraction System

**Priority:** ABSOLUTE

- Detail density progressively dissolves away from the face.
- Peripheral anatomy simplifies into painterly forms.
- Suggest rather than describe.
- Use larger brushstrokes outside focal regions.
- Increase lost-and-found edges toward the image periphery.
- Merge distant forms into larger value masses.
- Painterly abstraction is preferred over hyper-rendering.
- Peripheral simplification should appear intentional rather than unfinished.

---

# Detail Sacrifice Hierarchy

**Priority:** ABSOLUTE

When complexity increases, remove detail in this order:

1. Environment
2. Architecture
3. Secondary objects
4. Decorative elements
5. Lower clothing
6. Armor details
7. Hair
8. Props
9. Hands
10. Face

---

# Background Storytelling

**Type:** Narrative Context

The environment exists only to reinforce the character.

It should communicate profession, routine, social status and personality without becoming the subject of the illustration.

One dominant environmental element should naturally organize the composition, such as:

- desk
- workbench
- window
- counter
- chair
- doorway
- machinery
- shelving

The environment should feel inhabited rather than decorated.

Architecture should remain simplified.

Narrative objects should remain readable without becoming highly rendered focal points.

# 2D Rendering Standard

| Property | Direction |
|----------|-----------|
| Style | Arkane Studios Narrative Character Concept Art |
| Finish | Painterly |
| Brushwork | Clearly visible |
| Lineart | Minimal or absent |
| Construction | Sculptural planes |
| Shading | Large value masses before small details |
| Materials | Simplified painterly interpretation |

The illustration should celebrate the qualities of painting instead of attempting to imitate photography.

---

# Edge Control

| Region | Edge Treatment |
|---------|----------------|
| Face | Sharpest |
| Eyes | Sharpest |
| Upper Torso | Controlled |
| Hands | Moderately defined |
| Costume | Soft |
| Background | Mostly lost-and-found |

---

# Hair Rendering

- Build hair as large sculptural masses.
- Avoid excessive individual strands.
- Hair remains secondary to facial structure.

---

# Hand Rendering

Hands should remain readable and anatomically believable.

Painterly simplification is encouraged.

Avoid unnecessary finger detail.

Hands should support storytelling without competing with the face.

---

# Material Rendering

Represent materials through:

- shape
- value
- silhouette
- edge variation

Avoid relying on texture or reflective realism.

# Facial Identity Enforcement

**Priority:** ABSOLUTE

- Identity over attractiveness.
- Character over beauty.
- Facial structure over skin texture.
- Preserve user-defined facial proportions.
- Visible cheekbones.
- Visible orbital structure.
- Visible jaw planes.
- Visible forehead planes.
- Strong anatomical construction.
- Avoid same-face syndrome.

---

# Character Performance System

**Priority:** ABSOLUTE

Every pose should communicate:

- personality
- profession
- social status
- emotional state

Characters should appear captured during a believable moment of their routine rather than posing for the viewer.

Avoid:

- heroic poses
- fashion poses
- promotional poster poses
- exaggerated action poses

---

# Arkane DNA Enforcement

**Priority:** ABSOLUTE

Character design over rendering polish.

Structure over texture.

Planes over gradients.

Value masses over micro-detail.

Painting over realism.

Identity over beauty.

Narrative over decoration.

Concept art first.

Portrait second.

Characters should feel observed rather than staged.

The illustration should evoke a lived-in world without requiring a highly rendered environment.

---

# Fail Safe

Always protect:

1. Character identity
2. Facial structure
3. Painterly readability
4. Narrative clarity

If complexity becomes excessive, progressively simplify:

- environment
- architecture
- props
- costume
- hair
- hands

before sacrificing the quality of the face.
