# Exemplos de prompts de Astrael v2

Esta pasta contém cópias dos prompts da Isis Nefer e da Dorote Ross adaptados ao padrão v2 de corpo inteiro. Use-os para orientar o preenchimento dos seis campos, preservando a identidade de novos personagens.

O motor visual de referência para novas criações é sempre [astrael_geometrico_template.md](../astrael_geometrico_template.md). Siga as [instruções de criação](../instrucoes_criacao_personagem.md).

A referência de pintura é a [Isis no telhado](../referencias/isis_telhado.png). Essa imagem foi gerada antes destes prompts v2 e serve como alvo visual; não é apresentada como resultado exato dos arquivos desta pasta.

Os exemplos são cópias de referência. Alterações futuras nos personagens não os atualizam automaticamente.
